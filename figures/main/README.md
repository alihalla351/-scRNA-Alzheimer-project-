# Main figures

This directory contains the final exported main figures for the APP23 hippocampal snRNA-seq project.

- `Figure_1_combined.png` — combined UMAP/annotation overview
- `Figure_1A_UMAP_10_clusters.png` — UMAP of the 10 fine neuronal clusters
- `Figure_1B_UMAP_broad_subtypes.png` — UMAP of DG, CA1-like, CA3, and inhibitory populations
- `Figure_1C_marker_DotPlot.png` — canonical neuronal marker expression supporting annotation
- `Figure_2_pathway_remodeling.png` — summary of FDR-significant pathway-level remodeling across age and neuronal subtype
- `Figure_3_CellChat_strength_difference.png` — 24-month APP23 minus WT inferred interaction-strength differences
- `Figure_4_Cholesterol_Desmosterol_CellChat.png` — targeted cholesterol/desmosterol CellChat comparison

The PNG files are the final high-resolution exports used for presentation/manuscript assembly. Figure interpretation should follow the statistical and CellChat limitations documented in `docs/RESULTS_SUMMARY.md` and `docs/METHODS.md`.
