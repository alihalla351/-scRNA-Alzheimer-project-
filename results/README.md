# Results

This directory contains version-controlled numerical result summaries generated by the project. Large serialized R objects (`*.rds`) and raw GEO source files are intentionally excluded.

## Primary result groups

- mouse/sample-level pseudobulk edgeR APP23-versus-WT analyses
- ranked GO Biological Process GSEA
- DoRothEA/decoupleR TF activity with sample-level limma testing
- CellChat pathway and source-target interaction summaries
- integrated biological summary outputs

## CellChat results deposited in the repository

The `CellChat/` directory contains exact CSV summaries preserved from the completed 24-month WT-versus-APP23 analysis, including source-target interaction changes and targeted pathway summaries.

Interpret CellChat as descriptive condition-level analysis rather than replicate-level statistical inference. The source dataset contains neuronal nuclei only, so the inferred communication network does not include glia or other non-neuronal hippocampal populations.

## Interpretation

For a concise synthesis of the pseudobulk, GSEA, TF, and CellChat findings, see `docs/RESULTS_SUMMARY.md`.

Numerical outputs should be regenerated from `scripts/GSE141044_APP23_full_project.R` when a new analysis version is intentionally run; values should not be reconstructed from prose summaries.
